## Notes
### v1.1.4
Repository moved to [Codeberg](https://codeberg.org/Lluciocc/Vish) and licence changed to GPL-3.0-or-later! This makes sure our work and any fork stays free software for ever.

The edges (wires) now have more advanced features:
- Deletion -> Alt and click on the port
- Reconnection -> Ctrl + drag port
- Switch -> Start with Reconnection, Ctrl + drop on another wired port
- Replace -> Alt + drop on a wired port

A lot of backend work is done. Part of it is a completely new theme system. Since it gives more power to style Vish, we also adjusted many elements for a more polished look.
The about page got a lot of rework, too. So we could style it to make it much easier to read. Clicks on links now open a dialogue to ask about open or copy the link and not open browsers without permissions any longer.
The graphical interface is now fully adaptive from phone screen size to 4k monitors (and beyond). No touch support, yet.

### v1.1.1
New theme system ! You can now add your own themes by placing .yml files in the "themes" folder in your config directory.
Custom themes can be shared with others, and you can even create your own themes to share with the community ! Check [the repository](https://github.com/Lluciocc/vish-theme-collection) for more details on how to create themes.

### v1.1.0
New comments are out ! You can now mode nodes by group, changing the accent color, and more !

### v1.0.0
Vish is in Beta. Expect bugs and missing features. Stay tuned for updates!
You can find the latest updates in the repository: [Vish on GitHub](https://github.com/Lluciocc/vish)
